# C2AE Notebooks

This directory contains Jupyter notebooks for exploring and analyzing the C2AE model.

## Planned Notebooks

1. **01_data_exploration.ipynb** - Explore datasets and open-set splits
2. **02_model_analysis.ipynb** - Visualize model architecture and FiLM layers
3. **03_results_analysis.ipynb** - Analyze training results and open-set performance

## Usage

To use these notebooks, first install Jupyter:

```bash
pip install jupyter
```

Then start the Jupyter server:

```bash
jupyter notebook
```

Navigate to this directory in your browser and open the desired notebook.
